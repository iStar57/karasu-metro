## Store listing

**Name:** Karasu Metro

**Summary** (max 132 characters):

> Unofficial theme for karasu.live: a cleaner interface with a reworked match room, leaderboard, profiles and play page.

**Category:** Make Chrome Yours › Accessibility (or Fun, if Accessibility is rejected).

**Language:** English

**Description:**

```
Karasu Metro is an unofficial theme for karasu.live, the CS2 matchmaking site. It gives the site a cleaner, darker interface and reworks its busiest pages.

Open source: https://github.com/iStar57/karasu-metro

WHAT IT CHANGES
• Navigation: a tidier sidebar with grouped links, and a search box in the header that shows results as you type.
• Play page: queue and modes on one screen, with recent bans in a scrolling ticker.
• Match room: a compact team header, a full-width turn bar for map and server vetoes, rosters on both sides of the room, and condensed stats tabs.
• Leaderboard: a podium for the top three and each player's distance to first place.
• Profiles: a redesigned header, stat cards graded by performance, and a readable roles panel.
• Inventory: filter items by type.
• Notices: site-wide notices collapse to one line and can be dismissed.

SETTINGS
Use the toolbar popup to turn the theme on or off, pick an accent color, and restore dismissed notices.

PRIVACY
No analytics, no tracking, no remote code. The extension only runs on karasu.live and only stores your theme preferences and the notices you dismissed. Everything happens in your browser.

Karasu Metro is a community project. It is not made by or affiliated with Karasu, and it is published with the Karasu team's permission. Every button and link on the site is still Karasu's own, so the site works exactly as before.
```

## Privacy tab

**Single purpose:**

> Restyles the interface of karasu.live with a custom theme, and adds small layout improvements to its pages.

**Permission justifications:**

- **storage:** Saves the user's theme settings (theme on or off and the accent color), the site notices the user dismissed, and the site's language, so these are restored on the next visit.
- **Host permission (karasu.live and its subdomains):** Applies the theme and the layout changes to Karasu pages. The extension does not run on any other site.

**Remote code:** No. All code is in the package, and fonts are bundled.

**Data usage:** The extension reads the content of Karasu pages only to restyle them, and that processing never leaves the browser. Tick **Website content** only if the dashboard requires it for that local processing. Tick nothing under collection or transfer. Confirm the three certifications: no selling of data, no use unrelated to the single purpose, and no use for creditworthiness.

**Privacy policy URL:** `https://github.com/iStar57/karasu-metro/blob/main/PRIVACY.md`
