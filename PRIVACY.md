# Privacy policy: Karasu Metro

Last updated: 20 October 2026

Karasu Metro is a browser extension that restyles the Karasu website at `karasu.live`.

## Information the extension accesses

When you visit `karasu.live`, the extension reads the page's visible text and layout so it can apply the theme and its interface changes. All of this happens in your browser. The extension does not send page contents, account details, browsing history or any other website data to the developer, or to any analytics or advertising service.

## Information the extension stores

The extension stores three things:

- **Theme preferences:** whether the theme is on and which accent color you chose. These are saved with the browser's `storage.sync`, so your browser may synchronize them through your browser account.
- **Dismissed notices:** the identifiers of the site notices you have closed.
- **Page language:** the language the site is shown in.

Dismissed notices and the page language are saved only on your device, with `storage.local`. All three are used only to restore your settings.

## Sharing and retention

The developer does not receive or share any of this information. It stays in your browser's storage until you change it or uninstall the extension. You can restore dismissed notices from the extension's popup. You can delete all stored data by removing the extension or clearing its data in your browser settings.

## Source code

The full source code is public, so anyone can check what the extension does. The link is in the extension's store listing.

## Changes and contact

This policy will be updated if the extension's behavior changes. For privacy questions, open an issue in the source code repository or use the support contact on the Chrome Web Store listing.
