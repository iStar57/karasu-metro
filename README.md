# Karasu Metro

Unofficial theme for [karasu.live](https://karasu.live).

A darker, cleaner look for the whole site, plus reworked layouts for the play page, match room, leaderboard, profiles, inventory and utility. It only restyles the pages: every button and link is still Karasu's own.

Not affiliated with Karasu. Published with their permission.

## Privacy

No analytics, no tracking, no remote code. See [PRIVACY.md](PRIVACY.md).
